# iron-server

Scaffold a backend folder structure with one command.

## Usage

```bash
npx iron-server init my-api          # new folder
npx iron-server init .               # current folder
npx iron-server init my-api --lang ts
```

## Options
- `-l, --lang <js|ts>`  skip the language prompt
- `-y, --yes`           skip the confirmation when the folder is not empty
